The defect that reset the picture

Every v6 diagnostic was measured through a corrupted baseline

In the per-sample loop, other holds local positions into idx. The b_LOO aggregation maps them back correctly via G[idx[b]]. Two lines below did not, so b_obs and s² were read off rows 0…len(idx)−1 of the whole batch — arbitrary trajectories with no relation to the bucket.

What it cost

other = [b for b in range(len(idx)) if trajs[b] != trajs[a]]   # LOCAL positions
per[trajs[b]][0] += w[k] * G[idx[b]]        # correct
- s2    = float(np.var(G[other]))           # reads global rows 0..len(idx)-1
- b_obs = float(G[other].mean())            # same
+ oth   = [idx[b] for b in other]
+ s2    = float(np.var(G[oth]))
+ b_obs = float(G[oth].mean())

b_obs matched the correct leave-one-trajectory-out mean on 56.5% of rows, correlation +0.051, mean absolute error 0.627 (max 10.1). It carries weight (1−λ) on every sample and is the entire estimator wherever λ = 0 — 69.8% of samples in v6.

The r = 0.956 figure is the crux: a step credit that agrees with the baseline on 99.7% of sign decisions cannot steer the policy anywhere different. A discriminating φ is necessary to change that — it is not on its own sufficient.

Leakage control

The embedded context contains “you tried ‘X’ and then saw …”, where X came from the previous step’s admissible set while the label is the current one. Rebuilding the context from observation history alone, with no action strings, keeps the signal:

Context variantrawwhiten-1whiten-2whiten-3
Observation history, no action strings0.6550.6770.6880.682
Recent window only, with actions0.6170.6170.6880.706
Full context0.6590.7300.7710.795

Both components clear the 0.65 gate independently and the full context beats either by ~0.09 — complementary information, not leakage. Leakage would show the action-bearing arm carrying everything while the action-free arm fell to chance.

The secondary finding is the one with the widest reach: moving from an admissible-random corpus to the trained policy lifted even the unchanged bag-of-words φ from 0.492 to 0.568. Every earlier negative result in this project was scored on the random-policy distribution and is therefore suspect — including the two-level gate rejected at 98.9% singletons.

Open risks

What would still make the φ result wrong

  • Corpus quality. 45.2% of actions in the probe corpus were inadmissible pass-throughs from a hand-rolled generation loop. There is no logged training rate to compare against — episode/valid_action_ratio = 0.999 measures parser validity, not admissibility.
  • Dependent pairs. 4,925 same-pairs drawn from only 8 games. The quoted 51σ is optimistic; the effect is clearly large, but the interval is not that tight.
  • Necessary, not sufficient. The step term still acts only where a bucket holds ≥2 trajectories with disagreeing returns. ~44% of buckets are singletons and back off to A_CC = 0, and the shared episode advantage still dominates the gradient.
  • Whitening depth chosen post hoc. k = 3 was picked after seeing the curve. It is unsupervised — no labels enter — but it should be fixed in advance for the reported run.
Work order

Cheap validation first, GPU-days last

  1. Re-run the φ probe at 32 tasks with trainer-path generation. Confirms 0.795 holds and makes the pair statistics honest. ≈ 40 min · 1 GPU
  2. Re-score the two-level gate on the trained-policy corpus. That negative was measured on the random-policy distribution, which we now know understates everything. minutes · CPU, corpus cached
  3. Implement φ from the reference model’s whitened last-layer hidden state, with ρ set to the measured value. No extra forward pass — the reference model already runs for the KL term. implementation
  4. Matched two-arm run, publication-matched eval, both splits, three seeds on the best checkpoints. ≈ 30 h · GPUs 0–3, 6, 7

Steps 1 and 2 de-risk step 4. The prediction going in: a working metric moves the answer to “will CCPO beat GRPO” from no to unknown and worth testing — not to yes.
